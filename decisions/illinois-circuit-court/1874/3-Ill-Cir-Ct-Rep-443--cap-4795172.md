# McNeeley v. Wright

## Majority (Craig, J.:—)

Craig, J.:—
The appeal in this case was dismissed on account of the failure of the appellant to file an appeal bond within the time specified by the order of the court below. A motion is now made to set aside the order of dismissal. We think sufficient grounds have been shown, and the order will be set aside.
